# 快客小程序首页方案

状态：方案稿。确认前不改小程序代码。设计图见 [home-board.png](home-board.png)，稿见 [home.html](home.html)。

## 首页要解决的事

移动端用户要的是好玩，并且马上用得上。首页给出能看懂结果的例子，用户换上自己的照片，按例子复刻。

第一屏六张例子，分成两组。

实用：

- 旧照修复。划痕、折痕、褪色。
- 一键高清。对焦失败、糊掉的照片。
- 路人消失。景区和合影里多余的人。

好玩：

- 人物转 3D
- 人物转动漫
- 人物转 Q 版

每张实用卡是左右对比，左边处理前，右边处理后。每张好玩卡是结果大图，角上放原图。用户不用读说明，就能知道点进去会得到什么。

## 参照

参照美图秀秀和醒图：把效果本身放在首页，用户先看见「修好了 / 变清楚了 / 人没了 / 变成动漫了」，再决定要不要用自己的图做一次。

商品图和灵感瀑布流先离开第一屏。创作页仍可以自由描述，从底部中间的加号进去。

## 点进去之后

六种玩法共用一个复刻页，只换例子图和提示词。

1. 上看示例的前和后。
2. 上传自己的照片。没有照片时，允许先用示例生成，用来确认效果。
3. 底部一颗按钮：「用我的照片复刻」。

生成仍走现有 `POST /api/creative/generate`。用户的图作为参考图，玩法是一段固定提示词，例如「按示例把旧照片的划痕和褪色修好，保留人物五官」。模型质量决定效果上限，这一版先不单独立修复或消除接口。

## 界面

- 底色 `#f4f5f7`，卡片白底，圆角 16。
- 对比图中间一条白线，角标写「前 / 后」。
- 字用黑色。主按钮一颗，黑底白字，高 48。
- 首页标题下只有一句：「点一个例子，换上你的照片」。

图里的照片是同一位示意人物做出的前后效果，用来说明玩法。上线后例子可以换成运营配置的模板。
