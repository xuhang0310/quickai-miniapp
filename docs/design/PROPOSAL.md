# 快客小程序首页方案

状态：已按此方案开发。设计图见 [home-board.png](home-board.png)，稿见 [home.html](home.html)。

## 首页要解决的事

移动端用户要的是好玩，并且马上用得上。首页给出能看懂结果的例子，用户换上自己的照片，按例子复刻。

第一屏八张例子，分成两组。

实用：

- 去除水印。涂住水印，只补这一块。走现有擦除接口 `POST /api/ecommerce/erase/jobs`，不整张重画。
- 添加水印。在原图上叠一行字，选左下、右下或居中。在手机上完成，不走生图。
- 旧照修复。划痕、折痕、褪色。
- 一键高清。对焦失败、糊掉的照片。
- 路人消失。景区和合影里多余的人。

好玩：

- 人物转 3D
- 人物转动漫
- 人物转 Q 版

每张实用卡是左右对比，左边处理前，右边处理后。每张好玩卡是结果大图，角上放原图。用户不用读说明，就能知道点进去会得到什么。

## 参照

参照美图秀秀和醒图：把效果本身放在首页，用户先看见「修好了 / 变清楚了 / 人没了 / 变成动漫了」，再决定要不要用自己的图做一次。

商品图和灵感瀑布流先离开第一屏。创作页仍可以自由描述，从底部中间的加号进去。

## 点进去之后

去除水印和路人消失走现有擦除：涂住要去掉的地方，只补这一块。添加水印在手机上叠一行字，不生图。旧照、高清和变装共用一个复刻页，只换例子图和提示词。

1. 上看示例的前和后。
2. 上传自己的照片。复刻页没有照片时，允许先用示例图试一次。
3. 底部一颗按钮。复刻是「用我的照片复刻」，去除是「去掉涂抹区域」，加水印是「加上水印」。

复刻走现有 `POST /api/creative/generate`。用户的图作为参考图，玩法是一段固定提示词。小程序固定使用同一个生图模型，请求里带上，页面、分享和报错都不展示模型名称。

## 界面

- 底色 `#f4f5f7`，卡片白底，圆角 16。
- 对比图中间一条白线，角标写「前 / 后」。
- 字用黑色。主按钮一颗，黑底白字，高 48。
- 首页标题下只有一句：「点一个例子，换上你的照片」。

图里的照片是同一位示意人物做出的前后效果，用来说明玩法。上线后例子可以换成运营配置的模板。
